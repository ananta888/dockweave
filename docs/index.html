Zwei „Runtimes für Coding-Agents“ — aber auf verschiedenen Ebenen. Direkter Vergleich mit echtem Code aus beiden Repositories (ananta888/dockweave und herdrdev/herdr), inklusive Verknüpfungen und einer ehrlichen Einschätzung, was geht und was nicht geht.
